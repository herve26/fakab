# CRM Tool

A Customer Relationship Management tool built with Remix, React, and Supabase.

## About The Project

This project is a comprehensive CRM tool designed to help businesses manage their customer interactions, track sales, and manage projects. It provides a centralized platform for all customer-related data, making it easy to access and analyze customer information.

## Getting Started

To get a local copy up and running follow these simple steps.

### Prerequisites

* Node.js (v18 or later)
* npm

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/your_username_/Project-Name.git
   ```
2. Install NPM packages
   ```sh
   npm install
   ```
3. Set up your `.env` file by copying `.env.example` and filling in the required values.

## Usage

To start the development server, run:

```sh
npm run dev
```

This will start the app in development mode, rebuilding assets on file changes.

## Running the Tests

This project does not yet have any automated tests.

## Deployment

To deploy this application, you can use any Node.js hosting provider.

First, build your app for production:

```sh
npm run build
```

Then run the app in production mode:

```sh
npm start
```
